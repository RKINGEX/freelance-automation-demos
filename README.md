# Freelance Automation & AI Demos

A collection of practical automation and AI workflow projects built with n8n, APIs, webhooks, HTTP, CRM systems, and AI services.

## Projects

| Demo | Description | Technologies |
|---|---|---|
| Demo 01 — Leads CRM | Lead capture, validation, CRM storage and notifications | n8n, Webhooks, HTTP, Google Sheets |
| Demo 02 — WhatsApp Follow-up | Automated customer follow-up | n8n, WhatsApp API |
| Demo 03 — Appointment System | Automated appointment management | n8n, Calendar, Webhooks |
| Demo 04 — AI Document Processor | AI-powered document processing | n8n, LLM, APIs |

## Skills demonstrated

- Webhooks
- HTTP / REST APIs
- JSON
- n8n
- CRM automation
- Google Sheets
- API integrations
- AI workflows
- LLM integrations
- Automated notifications

## Goal

Build practical automation systems that help businesses reduce repetitive work, organize information, and improve customer operations.
